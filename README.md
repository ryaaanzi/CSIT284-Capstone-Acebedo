Project Description

The Clinic Visit Log is a Flutter application that allows students to log their clinic visits by providing their symptoms. Each visit is automatically recorded with a timestamp.

The nurse can view the list of submitted clinic visits, monitor the waiting queue, and mark visits as attended.

Core Features:

 Student clinic visit submission
 Automatic visit timestamp
 Nurse queue display
 Mark visits as attended
 Dummy clinic visit data for testing

Scope Limitations:

No medical records
No medicine inventory management

Technology:

Flutter
Dart
